# Public Release Review

This repository is designed to be public, but the tool cannot infer whether a new example contains private information. Review every added file manually.

Search for these classes before publishing:

- absolute paths and local usernames;
- email addresses, domains, IP addresses, URLs, and repository remotes;
- passwords, tokens, cookies, API keys, private keys, and authorization headers;
- private content, exports, logs, screenshots, backups, and generated data.

Use placeholders such as `example.org`, `user@example.invalid`, and `REDACTED` in public examples.
